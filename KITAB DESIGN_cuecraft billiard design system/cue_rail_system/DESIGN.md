## Brand & Style

This design system expresses the discipline, acoustic precision, and tailored craftsmanship of high-end billiard clubs and sporting salons. Rejecting both dive-bar grit and generic SaaS clichés, the aesthetic draws directly from table rail architecture: clean linear sightlines, flush diamond-sighting inlays, brushed brass mechanical fixtures, and tactile woolen cloths.

The core visual style is **Architectural Minimalism** merged with **Restrained Luxury**. Every view mirrors a master layout:
- **Atmosphere:** Controlled daylight filtering into an oak-and-slate hall. Warm ivory foundations offset by deep felt emeralds and sharp charcoal linework.
- **Tone:** Authoritative, measured, quiet, and exacting.
- **Geometry:** Pure Cartesian grids, flush dividers, hairline structural framing, and intentional diamond geometry.
- **Strict Anti-AI Principles:** Zero floating glass blurs, zero neon/purple gradients, zero skeuomorphic 3D billiard spheres, zero hyper-pill cards. Structure is conveyed through exact spacing, flush perimeter joins, and surgical 1px rules.

## Colors

The palette balances warm chalked-canvas neutrals against the unmistakable depth of tournament-grade worsted cloth.

### Foundations & Canvas
- **Canvas Default (`#FBF9F5`):** Warm chalk-white canvas establishing a calm, paper-like foundation.
- **Canvas Recessed (`#F7F5F0`):** Secondary structural background for table floor plans, side rails, and systemic sub-panels.
- **Surface Elevated (`#FFFFFF`):** Pure, clean card surfaces and operational popovers.
- **Surface Accentuated (`#F3EFEA`):** Low-contrast resting fill for headers, table rail caps, and structural groupings.

### Ink & Contrast Typography
- **Ink Primary (`#141615`):** Deep soot charcoal for primary headings, table IDs, and key values.
- **Ink Secondary (`#2B2E2C`):** Dense neutral for structural body copy and table metadata.
- **Ink Muted (`#5C625E`):** Secondary specs, rack times, and inactive indicators.
- **Ink Faint (`#8C938E`):** Micro-captions, diamond markings, and disabled states.

### Accent & Cloth System
- **Emerald Primary (`#0F5A47`):** Tournament cloth tone for primary CTAs, open states, and active confirmations.
- **Emerald Deep (`#0B4536`):** Press state and focused rail highlights.
- **Emerald Wash (`#E7F3EF`):** Subtle tinted fill for open session bookings and table availability badges.

### Table Status Tokens
Each status couples tone with a dedicated geometric anchor:
- **Open / Available:** Emerald `#0F5A47` (Wash `#E7F3EF`) with a solid circle glyph `●`.
- **Reserved / Booked:** Slate Navy `#2A3B50` (Wash `#EAF0F6`) with a sighted diamond glyph `◆`.
- **In-Play / Occupied:** Warm Amber `#9A5A18` (Wash `#FBF2E8`) with a measured pulse ring indicator.
- **Maintenance / Off-Cloth:** Terracotta Rust `#7A3535` (Wash `#F9EBEB`) with a rigid horizontal slash rule `—`.

### Structural Dividers
- **Border Default (`#E5E0D8`):** Architectural boundary line.
- **Border Strong (`#DCD6CD`):** Table perimeter frames and split view separators.

## Typography

Typography functions as a spatial gauge. Editorial sans-serif forms create clarity across managerial overviews, while technical monospaced figures handle match timers, table numbers, rack analytics, and rate breakdowns.

### Type Hierarchy Guidance
- **Display & Headlines (Plus Jakarta Sans):** Set with tight tracking and disciplined weight. Avoid loose display tracking; titles must hold structural density like stone carving.
- **Technical Monospace (JetBrains Mono):** Mandated for all time codes (e.g., `01:42:18`), rate metrics (`$65.00/HR`), table coordinates (`TBL-09-CAROM`), and sighting calibrations. Numbers must never shift width or disrupt grid alignment during live updates.
- **Labels & Metas:** Always set uppercase with deliberate tracking (`0.04em` to `0.06em`) when communicating operational states, membership tiers, or venue zones.

## Layout & Spacing

The layout philosophy mirrors the structural grid of a tournament floor: straight corridors, flush junctions, and unobstructed sightlines.

### Grid & Canvas Structure
- **Desktop (1200px+):** 12-column layout with 24px (`1.5rem`) gutters and 40px (`2.5rem`) margins. Main navigational rails snap flush to the left; operational sub-canvases utilize flush internal borders rather than floating margins.
- **Tablet (768px – 1199px):** 8-column layout with 16px (`1rem`) gutters and 24px (`1.5rem`) margins. Venue map reflows from multi-bay isometric into a vertically scrollable deck.
- **Mobile (< 768px):** 4-column layout with 12px (`0.75rem`) gutters and 16px (`1rem`) margins. Tables collapse into precise, rail-bordered inspection bars.

### Rhythmic Density
- Padding inside interactive containers follows a strict horizontal-bias rhythm (`space-md` vertical paired with `space-lg` horizontal) to mimic the widescreen aspect ratio of billiard tables.
- Layout sections are joined through continuous 1px hairline rules (`#E5E0D8`) rather than artificial empty gaps.

## Elevation & Depth

Visual hierarchy is articulated through **Tonal Stepping** and **Low-Contrast Structural Borders** rather than standard shadows.

### The Depth Model
- **Ground Floor (Base Canvas):** `#FBF9F5` forms the backdrop for the full room.
- **Sub-Rail Layer:** `#F7F5F0` defines table bay envelopes, lane gutters, and secondary filter ribbons.
- **Active Deck:** `#FFFFFF` is reserved for current focal points (active match scorecards, inspection drawers, input matrices).
- **Hairline Anchors:** Every layer change is defined by a 1px solid rule (`#E5E0D8`).

### Shadows
Standard drop shadows are prohibited for resting elements. When a floating state is functionally required (e.g., active cueing sheet, flyout detail panel, or time-picker popover), apply a single razor-thin ambient shadow:
- `box-shadow: 0 4px 20px -2px rgba(20, 22, 21, 0.06), 0 0 0 1px #DCD6CD;`
The shadow is desaturated soot, never pure black, tinted with ambient room warmth.

## Shapes

The geometric vocabulary honors the hardwood rail and diamond sight: crisp, stable, and minimally softened.

### Radius Constraints
- **Core Components (Cards, Inputs, Segmented Controls):** `0.25rem` (4px). Avoid circular or bubbly edges. All interactive elements must maintain an architectural corner.
- **Internal Panels / Bay Dividers:** Flat `0px` radius at borders that join adjacent structural components.
- **Floating Modals / Operational Sheets:** Maximum `0.5rem` (8px).
- **Status Diamond Glyph:** A 45-degree rotated 6px square (`transform: rotate(45deg)`), precision-aligned with typography baselines.

## Components

### Buttons
- **Primary:** Solid Emerald (`#0F5A47`), chalk white text, 4px border radius. Hover transitions to `#0B4536`. Active/press shifts by a 1px down-inset. No pill shapes.
- **Secondary / Ghost:** Clear background, 1px perimeter border in `#DCD6CD`, soot text (`#141615`). On hover, fills to `#F3EFEA` with no border color jump.
- **Destructive:** Deep terracotta tint with `#7A3535` border and text.

### The Trajectory Line (Signature Interaction)
- Every navigation tab, table view switcher, and sidebar selection uses the **Trajectory Line**: a crisp 1.5px directional rule (`#0F5A47`) snapping directly beneath active tabs or vertically along the left rail of active drawer items. Hovering animates this line outward from its origin like a cue stick stroke.

### Table & Venue Status Cards
- Structured like table profiles: 1px border (`#E5E0D8`), ivory canvas (`#FFFFFF`).
- Top banner features a monospaced table identifier (e.g., `TBL-04 [9-FT BRUNSWICK]`), right-aligned status badge, and an integrated session timer running in JetBrains Mono.
- State indicators are strictly paired:
  - **Open:** `#E7F3EF` background + `#0F5A47` text + filled circle `●`.
  - **Reserved:** `#EAF0F6` background + `#2A3B50` text + diamond `◆`.
  - **In-Play:** `#FBF2E8` background + `#9A5A18` text + active pulse dot.
  - **Maintenance:** `#F9EBEB` background + `#7A3535` text + dash `—`.

### Inputs & Selectors
- Background `#FFFFFF`, border 1px solid `#DCD6CD`, 4px radius.
- Focus state: Replaces border with 1px `#0F5A47` and a 1px outer ring `rgba(15, 90, 71, 0.15)`. No thick blue rings.
- Monospace auxiliary labels for rates, times, and member IDs sit flush to the right inside inputs.

### Lists & Data Grids
- Clean tabular layouts with zero alternating zebra striping.
- Rows separated by 1px hairline rules (`#E5E0D8`). Hover row state applies a subtle wash of `#F7F5F0`.
- All financial, temporal, and numeric data is strictly right-aligned using JetBrains Mono tabular figures.
